# onc-media

Public media for **Outta Nowhere Cards** (ONC). Reels live in `reels/` and are posted to the ONC Facebook Page from their raw GitHub links.

- `tools/make_reel.py` builds a 1080x1920 hype reel from a JSON spec
- `brand/` logo, banner and rotating brand-reel themes
- `RUNBOOK.md` the steps each scheduled autopost run follows

Any card. Any sport. Anytime. https://on-cards.com
